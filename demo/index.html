Photosynthesis happens in chloroplasts. Chlorophyll absorbs sunlight and uses its energy to turn water and carbon dioxide into glucose, which feeds the plant. Oxygen is released through tiny pores called stomata. Almost all life on Earth depends on this process.

Authored variants

API in one table

Every direct child with data-min is a variant. The component picks the largest data-min that fits, inside its optional data-max range, and falls back to the smallest variant when nothing fits.

AttributeMeaning
data-minMinimum width in px. Default 0.
data-maxOptional maximum width in px for bounded ranges.
data-nameLabel delivered in the adaptive-change event.
basiscontainer (default, element width) or viewport (window.innerWidth).
Event + re-check
const ac = document.querySelector('adaptive-content');
ac.addEventListener('adaptive-change', e => {
  console.log(e.detail.variant); // "Deep Dive"
  console.log(e.detail.width);   // 560
});
ac.update(); // force re-evaluation
SSR: avoid flash of all variants
adaptive-content:not(:defined) > :not(:first-child) {
  display: none;
}

React wrapper

Forwarded ref, TypeScript types, and an onChange(detail) prop. Use plain elements as variants.

Header.jsx
import { AdaptiveContent } from '@codergartenau/adaptive-content/react';

<AdaptiveContent basis="container" onChange={d => console.log(d.variant)}>
  <p data-name="tiny" data-min={0}>Plants turn light into food.</p>
  <p data-name="long" data-min={400}>Full explanation…</p>
</AdaptiveContent>

Why not pure CSS container queries?

CSS hides; this component decides, defers, and reports.

<adaptive-content>CSS @container
AuthoringPlain HTML, Markdown and CMS friendlyHand-written queries per breakpoint
Lazy DOM<template> cloned only when selectedWhole subtree rendered and evaluated
Telemetryadaptive-change event with variant + widthNo native JS event for the active rule
